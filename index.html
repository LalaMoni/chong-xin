云端同步 · Supabase

登录后自动加载云端数据，编辑后自动同步。离线改动会等待联网，发生冲突时暂停同步并提示处理。建议定期保存 JSON 备份。

正在准备云端连接…

自动同步默认开启，无需手动上传或合并。发生同一藏品的跨设备冲突时，不会静默覆盖；请先保存 JSON 备份并按提示处理。图片存入私人 Storage。

自定义属性管理

默认属性保持不变。自定义属性可以改名、调整顺序或移出选项。改名会同步更新已使用该属性的藏品；移除选项不会删除藏品。

默认属性：Z&S · 22X · SU · TOP · 跨代

修改历史与撤销

每次保存、删除、导入或清空前都会记录一个还原点。可撤销上一步，也可恢复到某次操作之前。最多保留最近 8 个还原点；若浏览器空间不足，历史仅在本次打开期间保留。重要数据仍建议保存 JSON 备份。

数据检查

检查重复 ID、未成功关联套装的子记录、未填写发布时间的 SET，以及可能重复的记录。只检查，不会自动修改或删除数据。
